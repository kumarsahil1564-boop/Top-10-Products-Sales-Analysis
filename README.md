# Top 10 Products Sales Analysis

## 📌 Project Overview

This project identifies the Top 10 products based on total sales using Python and a sample Superstore dataset.

## 🎯 Objective

- Identify the top 10 products by sales
- Practice sorting and ranking
- Analyze product-level sales performance
- Visualize the results using a bar chart

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- CSV Dataset
- GitHub

## 📊 Methodology

1. Load the Superstore sales dataset.
2. Group the data by Product Name.
3. Calculate total sales for each product.
4. Sort products in descending order of sales.
5. Select the Top 10 products.
6. Create a horizontal bar chart.
